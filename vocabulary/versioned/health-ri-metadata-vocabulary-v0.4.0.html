Description

  • The Health-RI Metadata Vocabulary defines reusable terms for expressing aspects of health dataset metadata. Each term has a persistent identifier and a documented meaning, supported by RDF/OWL definitions. Usage examples and accompanying SHACL shapes help implementers apply and validate the terms in metadata records. The terms are intended for use, alongside externally defined terms, in the Health-RI Metadata Schema.

  • Development release for review. The entire vocabulary is versioned together using Semantic Versioning; term IRIs remain unversioned. This release does not assert approval or adoption by a particular Health-RI Metadata Schema release.

Object Property Definitions

anatomical location covered op

IRI https://w3id.org/health-ri/metadata-vocabulary#anatomicalLocationCovered
Is Defined By Health-RI Metadata Vocabulary
Description

  • The anonymous range is an owl:hasValue restriction on rdfs:subClassOf with value http://snomed.info/id/91723000. Under OWL Full / RDF-Based Semantics, every linked value is therefore a subclass of that root. Subclass transitivity and reflexivity include indirect subclasses and the root itself. This metamodeling pattern is outside OWL 2 DL. It entails subclass membership; it does not validate whether SNOMED CT already establishes that membership, require a SNOMED-owned IRI, or verify concept status. Use SNOMED CT anatomical class IRIs for the intended terminology binding. No skos:Concept typing is required for these values.

  • Relates a dataset to an anatomical class that is Anatomical structure (SNOMED CT 91723000) or one of its subclasses, describing anatomical coverage of the dataset as a whole at metadata or catalogue level.
Scope Note

Describes aggregate anatomical coverage of the dataset. Multiple values may be supplied; use is optional (0..*). Values identify anatomical classes, not individual organs, patients, samples, or observations. For a dataset combining data categories or modalities, this property does not pair a particular anatomical location with a particular category, modality, or record. The accompanying SHACL shape requires Dataset subjects and SNOMED CT IRIs with a supplied rdfs:subClassOf path to Anatomical structure, including the root itself. Validate against a separately trusted SNOMED hierarchy without applying the vocabulary's range inference; the OWL Full range axiom alone does not establish terminology membership.
Example 
A dataset covering the lung may link directly to http://snomed.info/id/39607008 (Lung structure), an anatomical class subsumed by http://snomed.info/id/91723000. The range axiom also entails that subclass relationship.

health condition of interest op

IRI https://w3id.org/health-ri/metadata-vocabulary#healthConditionOfInterest
Is Defined By Health-RI Metadata Vocabulary
Description

  • Values must be IRIs identifying SNOMED CT or ICD-10 concepts and are modelled as skos:Concept in the metadata graph, following the Health-RI Metadata Schema convention. The accompanying SHACL shape checks IRI-valued objects, skos:Concept typing, and conformity to the SNOMED CT or WHO ICD-10 identifier format. These checks do not verify that the identified concept exists, is active, or represents an appropriate clinical condition. The range declaration does not verify terminology membership.

  • Relates a dataset to a SNOMED CT or ICD-10 concept representing a disease, disorder, or other clinical condition that the dataset concerns as a whole.
Scope Note

Use this property to describe health conditions of interest in dataset-level metadata and catalogue records. Multiple values may be provided. Select only SNOMED CT or ICD-10 concepts that represent diseases, disorders, or other clinical conditions. The relation does not assert that any individual participant has been diagnosed with a condition and is not intended to enumerate diagnoses in individual records.
Example 
A dataset concerning myocardial infarction may use this property with http://snomed.info/id/22298006 (SNOMED CT: Myocardial infarction) as its value. In the metadata graph, the linked resource is typed as skos:Concept. The relation describes the dataset's subject matter without asserting a diagnosis for any individual participant.
